## 功能

- **仅保留网易云音乐**，在游戏内扫码登录
- **登录后才能搜索**歌曲，并使用自己账号里的歌单
- **液态玻璃播放器**（默认按 `M`）：歌单列表 / 封面墙两种视图，设置都在侧栏的 ⚙ 里
- **3D 歌词**：逐字歌词漂浮在世界里，带发光、抖动、文闪等效果
- **灵动岛**：显示正在播放的歌曲，并集成通知功能
- **在线播放**：接收并播放在线音频，同步显示歌词
- 一起听歌：暂未开放

## 运行环境
